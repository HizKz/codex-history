# Security Policy

Please do not report vulnerabilities in a public issue. Use GitHub's
[private security advisory form](https://github.com/HizKz/codex-history/security/advisories/new).

Conversation data is sensitive. Reports involving unintended network transfer,
overly broad file permissions, command execution, or leakage through the search
index are treated as high priority.

Only the latest released version receives security fixes.

Reports should include the affected codex-history and Codex CLI versions,
impact, and synthetic reproduction steps. Do not include real conversation
content, credentials, usernames, absolute home-directory paths, command output,
or MCP payloads.
